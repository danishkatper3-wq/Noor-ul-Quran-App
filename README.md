# 📖 Noor Al-Quran

### Read the Quran. Understand its Message. Memorize with Purpose.

Noor Al-Quran is a multilingual Quran application designed to make reading, understanding, listening to, and memorizing the Holy Quran easier. It aims to bring authentic Quranic text, trusted translations, audio recitation, AI-assisted Tafsir, Tajweed learning, and Hifz tracking into one accessible platform.

## ✨ Features

- 📚 **Quran Reader:** Read the Holy Quran and browse all 114 Surahs.
- 🌍 **Multiple Languages:** Arabic, Urdu, and English interface options.
- 📖 **Authentic Translations:** Access published translations from trusted sources.
- 🎧 **Audio Recitation:** Listen to Quranic recitations from supported providers.
- 🤖 **AI-Powered Tafsir:** Explore verse explanations grounded in identifiable, trusted sources.
- 🕌 **Tajweed Learning:** Learn Quranic pronunciation and recitation rules.
- 📈 **Hifz Tracking:** Track memorization progress and review saved passages.
- 🔖 **Bookmarks:** Save Ayahs for quick access.
- 🔍 **Search:** Find Surahs, Ayahs, and available translations.
- 🌙 **User-Friendly Design:** Responsive interface with dark mode support where implemented.
- 📱 **Mobile Support:** Designed for use on desktop and mobile devices.

## 🛡️ Quranic Accuracy and Responsible AI

Quranic accuracy is a core principle of Noor Al-Quran.

- Original Arabic Quranic text must come from a trusted Quran data source and must never be generated by AI.
- Urdu and English translations must come from identifiable, published sources. AI must never create translations that are presented as authentic published translations.
- The preferred Urdu translation is Fateh Muhammad Jalandhry's published translation, where legally and technically available.
- AI-generated Tafsir must remain separate from Quranic text and published translations.
- Tafsir explanations should cite real, verifiable sources.
- The application must not invent references, quotations, or religious rulings.
- Users should consult qualified Islamic scholars for religious rulings and complex questions.

## 🏗️ How It Works

1. Retrieve authentic Arabic Quranic text from a trusted provider.
2. Retrieve published translations with appropriate attribution.
3. Provide audio recitation through supported audio sources.
4. Retrieve relevant Tafsir material before generating AI-assisted explanations.
5. Display verifiable source references alongside Tafsir.
6. Keep Quran text, translations, and AI explanations clearly separated.
7. Allow users to access supported learning, bookmarking, and memorization features.
